Outlook 369 lets every user of your WordPress site connect their own Outlook.com or Microsoft 365 mailbox, read and send email from your site, and let AI draft or send replies using a prompt they write. This guide takes you from zero to a working inbox in about ten minutes.

✨Overview

📬

A full mail app

Folders, search, read, threaded replies, forward, flag, archive, delete and attachments, inside any page with [outlook369].

👤

One mailbox per user

Each WordPress user connects their own Microsoft account. Tokens are encrypted per user.

🤖

AI that writes like you

Draft a reply with one click, or let auto-reply answer new mail every 5 minutes with your prompt.

💬

Talk to your inbox

With Maylo AI: “what new emails do I have?”, summaries, replies and new emails from the chat, even by voice.

🛡️

Private by design

Mail is fetched live from Microsoft and never stored in WordPress.

🩺

Clear diagnostics

Every connection attempt is logged with Microsoft's exact answer.

🧭How it works

  1. The user opens your mail page and clicks Connect Outlook account.
  2. They sign in on Microsoft's page — your site never sees the password — and approve the permissions.
  3. Microsoft returns a one-time code. Outlook 369 exchanges it for tokens using OAuth 2.0 with PKCE and stores them encrypted for that user.
  4. The mail app, the AI assistant and Maylo AI then call Microsoft Graph v1.0 for that user. Tokens refresh automatically.

✅Before you start

You needNotes
🌐 A WordPress site on HTTPSWordPress 6.0+, PHP 7.4+ with the OpenSSL extension.
🔑 A Microsoft Entra (Azure) accountFree. Used once by the site owner to register the app.

🤖 Maylo AI optionalNeeded for AI replies, auto-reply and the email tools in the chat.
Azure account made with Gmail?The directory Azure created for you has no mailbox. Signing in with it shows a name like you_gmail.com#EXT#@yourname.onmicrosoft.com and Microsoft answers OrganizationFromTenantGuidNotFound. Sign in with an @outlook.com (free) or Microsoft 365 mailbox instead.

1Register the app in Microsoft Entra (Azure)

  1. Open entra.microsoft.com → Identity → Applications → App registrations → + New registration.
  2. Name: something your users will recognize, e.g. My Site Mail.
  3. Supported account types: “Accounts in any organizational directory and personal Microsoft accounts”.
  4. Redirect URI: platform Web, value = the URI shown in WordPress → Settings → Outlook 369 (default https://your-site.com/?outlook369=callback). Click Register.
  5. Certificates & secrets → + New client secret → copy the Value column immediately (not the Secret ID).
  6. API permissions → + Add a permission → Microsoft Graph → Delegated: User.ReadMail.ReadWriteMail.Sendoffline_access (plus openid, profile, email). In a work tenant click Grant admin consent.
  7. Overview → copy the Application (client) ID.
Exact match requiredThe redirect URI must match character by character — https, the trailing / and ?outlook369=callback. A mismatch causes invalid_request / AADSTS50011.

2Configure WordPress

Field in Settings → Outlook 369What to enter
Application (client) IDThe ID from the app's Overview page.
Client secretThe secret Value (stored encrypted with AES-256-GCM).
Directory (tenant)common — personal and work accounts (recommended) · consumers — only Outlook.com · organizations or a tenant ID — only work accounts.
Who can use the mailboxAny logged-in user, or only users with a specific capability.
Sending, images, attachmentsYour preferences. Attachments up to 3 MB per message.

Then place the shortcode on any page, for example inside your user panel:

[outlook369 title="My Mail" height="760"]
Keep the secret in wp-config.php instead 
define( 'OUTLOOK369_CLIENT_ID', '00000000-0000-0000-0000-000000000000' );
define( 'OUTLOOK369_CLIENT_SECRET', 'your-secret-value' );
define( 'OUTLOOK369_TENANT', 'common' );

3Users connect their mailbox

The inbox loads on your site right away. Users can disconnect at any time from the bottom of the folder list; their tokens are deleted immediately.

TipIf the wrong Microsoft account was used, the mail page offers Use a different Microsoft account, which disconnects and opens the account picker again.

🤖AI replies and auto-reply

✨ AI reply button

Open any email and press ✨. The AI writes a reply in the sender's language using your prompt and signature, then opens it in the compose window so you can edit and send it.

✨ AI panel (top bar)

SettingWhat it does
Automatic smart repliesOn / off. Only emails that arrive after you turn it on are answered.

Your reply promptHow to answer: your business, tone, what to offer, what never to promise.
SignatureAdded to every AI reply.
Max replies per daySafety limit, default 20.
Focused inbox only · Skip no-reply sendersKeeps newsletters and notifications out.

Example prompt 
You are the assistant of Virtual Copilot, an AI automation agency in the Netherlands.
Answer in a short, warm and professional tone. For new leads, thank them and offer a
free 15-minute discovery call. Never quote prices or deadlines; say we will follow up.
If someone asks for support, ask for their order number.
Runs every 5 minutesAuto-reply uses WP-Cron (max 5 emails per run). For reliable timing add a server cron job:
*/5 * * * * wget -q -O - https://your-site.com/wp-cron.php?doing_wp_cron >/dev/null 2>&1

AI replies are written by Maylo AI and charged to the user's wallet like any other Maylo AI request.

🔐Security and privacy

🔑

Sign-in

Microsoft identity platform, authorization code flow with PKCE and a one-time state.

🗝️

Tokens

Encrypted per user with AES-256-GCM, key derived from your WordPress salts.

📭

Mail data

Fetched live from Microsoft Graph, never stored in the WordPress database.

🧱

Email display

Sandboxed iframe with a strict Content-Security-Policy; scripts, forms and frames removed.

🖼️

Tracking pixels

Remote images blocked by default.

🚪

Disconnect

Deletes the user's tokens immediately; deleting a WordPress user deletes theirs too.

❓FAQ

Does the site see my Microsoft password?

No. You sign in on Microsoft's own page; the site only receives tokens that it stores encrypted.

Can one user read another user's mail?

No. Every token belongs to one WordPress user and is checked on every request.

Is my email copied into WordPress?

No. Messages and attachments are fetched live from Microsoft each time. Only the AI activity log keeps a short note of what was answered.

Does it work with Gmail?

This plugin is for Outlook / Microsoft 365. Gmail is handled by Google services in the VirtualCopilot user panel.

Will the AI reply to newsletters or no-reply senders?

No — they are skipped by default, and the AI itself can decide an email needs no reply.

How do I stop everything?

Turn off auto-reply in the ✨ panel, or click Disconnect. Disconnecting deletes the stored tokens.

🧑‍💻For developers

PHP API (used by Maylo AI)

$o = Outlook_369::instance();

$o->api_is_connected( $user_id );                                   // bool
$o->api_status( $user_id );                                         // account + auto-reply state
$o->api_list( $user_id, array( 'folder' => 'inbox', 'unread_only' => true, 'limit' => 10 ) );
$o->api_get( $user_id, $message_id );                               // full message, body as text
$o->api_send( $user_id, array( 'to' => 'a@b.com', 'subject' => 'Hi', 'body' => 'Text' ) );
$o->api_reply( $user_id, $message_id, 'Text', array( 'reply_all' => false, 'draft' => false ) );
$o->ai_draft_for( $user_id, $message_id, 'optional instruction' );  // AI reply text + html
$o->ai_settings( $user_id );
$o->ai_save_settings( $user_id, array( 'auto' => true, 'mode' => 'draft' ) );

All methods return arrays or a WP_Error.
